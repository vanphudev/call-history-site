# Call History Shipper Site

Static GitHub Pages site for the Call History Shipper app.

## Pages

- `/` landing page
- `/privacy-policy/`
- `/terms/`
- `/support/`
- `/contact/`
- `/data-sources/`
- `/data-disclaimer/`

## GitHub Pages

This site is designed to be served from the repository root on the `main` branch.

Default project URL after Pages is enabled:

`https://vanphudev.github.io/call-history-site/`

Recommended Privacy Policy URL for Google Play:

`https://vanphudev.github.io/call-history-site/privacy-policy/`

## Contact Placeholder

The public support channel currently points to GitHub Issues and the developer website. Replace or add a dedicated support email before the Google Play submission if you want the policy pages to show an email address.
